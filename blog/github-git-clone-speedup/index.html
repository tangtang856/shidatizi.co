程序员必备！彻底解决 GitHub 打不开与 Git Clone 超时慢如蜗牛

📅 发布日期：2026-03-01 ✍️ 作者：十代梯子技术研究小组 🔒 原创保护：转载请注明出处

敲一行 git clone 常常报 Failed to connect to github.com port 443: Timed out。 只需在本地终端输入以下配置，强制 Git 走本地 Clash 代理端口： 

git config --global http.https://github.com.proxy http://127.0.0.1:7890
git config --global https.https://github.com.proxy http://127.0.0.1:7890
