隐私政策

在 shidatizi.co，我们深知在网络加速与隐私安全领域，个人数据保护至关重要。 本政策向您说明我们如何收集、使用和保护您的信息。

一、零敏感信息收集原则

  • 静态纯净架构：本站采用现代纯静态 HTML 与原生 CSS 架构，不设强制用户注册系统，不收集您的真实姓名、电话号码或支付账号；
  • 零第三方分析追踪探针：我们拒绝安装任何可能将用户浏览轨迹出售给广告商的重型画像脚本；
  • 本地闭环搜索：站内搜索与机场横向对比工具完全在您的本地浏览器前端由原生 JavaScript 运算完成，不向服务器发送您的搜索词日志。

二、基础服务器访问日志

与所有部署在 Cloudflare 等主流 CDN 上的网站一样，当您访问本站时，基础网络层可能会记录必要的系统级日志（包括访问时间、请求的网页路径、状态码以及用于防范 DDoS 恶意攻击的 IP 地址）。 这些数据仅用于保障系统安全与防范恶意爬虫，绝不用于身份关联。

三、外部链接安全提示

本站包含前往各大开源软件托管平台（如 GitHub）或第三方机场服务商的外部链接。 我们对第三方网站的隐私条例和安全防护不承担直接法律责任，建议您在访问任何外部平台时先行阅读其隐私政策。
