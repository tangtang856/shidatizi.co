OpenWrt 软路由 PassWall 插件安装与全屋智能分流全指南

手把手教你在OpenWrt固件上配置PassWall科学上网插件。涵盖节点订阅自动更新、DNS防污染分流与电视主机全屋无感翻墙。

想要让家里的 iPhone、安卓、电视盒子（Apple TV）、游戏机（Switch/PS5）全部免装客户端就能自动翻墙？ 在 OpenWrt 软路由 上部署 PassWall 是最成熟、最稳定的解决方案。

一、安装与节点订阅

  1. 登录 OpenWrt 后台，进入 「服务」→「PassWall」；
  2. 点击「节点订阅」，添加机场提供的 SSR / V2Ray / Trojan 格式订阅；
  3. 点击「保存并更新」，所有海外节点自动同步。

二、主开关与 DNS 分流

在「基本设置」中将 TCP 节点与 UDP 节点指定为所选专线节点。 DNS 解析建议使用 Chinadns-NG 进行境内外分流，彻底消除 DNS 投毒与泄漏。
