iPhone与iPad苹果客户端Shadowrocket配置教程

📅 更新时间：2026年3月 💻 适配系统：IOS ✅ 校验状态：实机测试通过

在 iOS 生态下，Shadowrocket（俗称“小火箭”） 是最经典、普及度最高且维护最频繁的科学上网客户端。 由于众所周知的政策原因，Shadowrocket 在中国大陆区 App Store 已下架，需使用非国区（如美区、港区）Apple ID 购买下载。

一、准备工作：非国区 Apple ID

  1. 准备一个美区或港区 Apple ID（可自行在苹果官网注册，或在第三方可信平台购买礼品卡兑换）；
  2. 打开 iPhone 自带的 App Store，退出当前国区账号，登录你的非国区账号；
  3. 搜索 Shadowrocket（注意认准开发者为 PanGu GmbH，图标为一个发射的小火箭，售价为 $2.99 美元，切勿下载盗版山寨应用）；
  4. 下载安装完成后，退出外区ID并换回你平时使用的国区ID，已下载的小火箭仍可正常永久使用。

二、一键导入机场订阅

  1. 用手机自带 Safari 浏览器登录你的 机场后台；
  2. 点击“一键导入 Shadowrocket”或复制专属订阅链接；
  3. 若点击一键导入，系统会自动唤醒小火箭并自动填充保存；
  4. 若是手动复制，打开小火箭，点击右上角加号 +，类型选择 Subscribe，在 URL 中粘贴链接并保存。

三、路由设置与启动

  1. 在小火箭主界面，将“全局路由”设定为 配置 (Config)（相当于规则分流，绝不能选“全局”）；
  2. 在节点列表中勾选一个节点，最上方开启连接开关；
  3. 首次启动会弹出 iOS 系统权限提示：“Shadowrocket 想要添加 VPN 配置”，点击“允许”并输入手机锁屏密码；
  4. 屏幕右上角出现 VPN 小方块图标，打开 Safari 浏览海外网站即可。
💡 开启按需连接（息屏省电）： 进入小火箭 -> 设置 -> 按需连接，开启此选项后，手机在息屏或休眠时不会保持持续心跳，能极大延长iPhone电池续航。
