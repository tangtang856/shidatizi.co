iOS 平台 Quantumult X (圈X) 策略组配置与重写教程

深度讲解Quantumult X（圈X）的节点订阅、分流策略组、MitM证书安装与去广告脚本配置，打造专属iOS网络利器。

Quantumult X（圈X） 是 iOS 平台上最具可玩性的专业网络调试与代理利器。 通过其强大的分流矩阵与 JavaScript 重写引擎，你可以精准控制每一条网络请求的流向。

一、添加服务器资源

点击右下角风车图标，在「节点」栏目点击「引用 (订阅)」，点击右上角「+」号，粘贴机场提供的专用 QX 订阅链接并保存更新。

二、配置策略组

在策略组中可自由创建“流媒体”、“海外AI”、“国内直连”等自定义组，将不同地区的专线节点分配给对应的服务，实现全自动分流。
