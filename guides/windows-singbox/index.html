Windows 平台 Sing-box 官方图形客户端快速上手指南

Sing-box官方图形客户端在Windows系统的配置教程。体验下一代轻量高性能通用代理平台的极致速度与低内存占用。

Sing-box 作为目前代理协议领域的后起之秀与性能天花板，以纯 Go 语言编写，具备惊人的内存控制能力与超高速的并发吞吐量。

一、下载安装 Sing-box for Windows

前往 Sing-box 官方 GitHub 仓库下载预编译好的图形界面安装包 sing-box-windows-amd64.zip 或 Windows MSI 安装包。 安装完成后启动软件，其界面极其克制优雅。

二、导入配置与节点选择

  1. 在机场后台（如 闪跃 FlashLeap）获取专门的 Sing-box 订阅链接；
  2. 在客户端 Profiles 面板中点击新建，类型选择 Remote，粘贴订阅链接并完成拉取；
  3. 在 Dashboard 仪表盘选择节点组，开启顶部的「Enable Proxy」即可享受极低开销的出海冲浪。
