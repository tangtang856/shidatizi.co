macOS系统翻墙客户端配置与优化教程

📅 更新时间：2026年3月 💻 适配系统：MACOS ✅ 校验状态：实机测试通过

对于搭载 Apple Silicon (M1/M2/M3/M4) 系列芯片或 Intel 处理器的 macOS 系统， Clash Verge Rev (Mac版本) 是目前体验最优秀的客户端，完美兼容系统暗黑模式并具备低功耗特性。

一、下载与安装指南

  1. 访问 Clash Verge Rev 官方发布页，下载 .dmg 镜像包：
    • M系列芯片（Apple Silicon）：下载 Clash.Verge_aarch64.dmg；
    • 老款 Intel 芯片：下载 Clash.Verge_x64.dmg。
  2. 打开 dmg 镜像，将 Clash Verge 图标拖入 Applications（应用程序） 文件夹中；
  3. 若首次打开提示“开发者无法验证”，在系统设置 -> 隐私与安全性 中点击“仍要打开”即可。

二、配置订阅与代理

  1. 打开软件，点击左侧 订阅 (Profiles)；
  2. 粘贴你在 专线机场推荐 中获取的订阅链接并点击导入；
  3. 在 代理 (Proxies) 页面选择 规则 (Rule) 模式并选定节点；
  4. 打开“系统代理”开关即可生效。
💡 开发者必备：如何给终端 (Terminal/iTerm2) 加速： 默认情况下，Mac 终端命令行中运行 git clone 或 npm install 不会走系统代理。 你可以进入 Clash Verge 设置，开启 Tun 模式，软件会自动接管系统网络栈；或者在终端中运行导出临时代理变量： 
export http_proxy="http://127.0.0.1:7897"
export https_proxy="http://127.0.0.1:7897"
