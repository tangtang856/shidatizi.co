Windows电脑翻墙客户端配置与使用教程

📅 更新时间：2026年3月 💻 适配系统：WINDOWS ✅ 校验状态：实机测试通过

在 Windows 10 与 Windows 11 环境下，Clash Verge Rev 是目前最受推崇的现代代理图形化客户端。 它拥有现代化的美观界面，深度集成了 Mihomo (Clash.Meta) 核心，并完美支持 Tun 虚拟网卡接管系统全局流量。

一、下载与安装 Clash Verge Rev

  1. 访问 Clash Verge Rev 官方 GitHub Releases 仓库（认准开源原版）；
  2. 根据你的电脑CPU架构选择安装包：64位Intel/AMD芯片请下载 Clash.Verge_x64-setup.exe；
  3. 双击运行安装程序，按默认步骤完成安装并启动软件。

二、导入机场订阅链接

  1. 登录你在 shidatizi.co 推荐的机场 后台，复制你的专属 Clash 订阅链接；
  2. 打开 Clash Verge Rev，在左侧导航栏点击 订阅 (Profiles)；
  3. 在顶部的输入框中粘贴刚才复制的订阅 URL，随后点击 导入 (Import) 按钮；
  4. 导入成功后，列表会出现对应的配置卡片，右键该卡片点击“选择使用”使之高亮显示。

三、选择节点与开启代理

  1. 点击左侧导航栏的 代理 (Proxies) 菜单；
  2. 确保顶部代理模式选择为 规则模式 (Rule)（此模式下国内网站直连不耗流量，海外网站走代理）；
  3. 在“节点选择”分组中，展开节点列表，点击右上角的闪电图标进行批量测速，选择一个延迟较低的节点（如香港专线、日本节点）；
  4. 在软件左下角或者“设置”页面，打开 系统代理 (System Proxy) 开关；
  5. 打开浏览器访问 Google 或 YouTube，测试是否秒开加载。
💡 开启 Tun 模式解决外服联机与终端报错： 如果你需要打外服游戏、使用Git命令行或某些不遵循Windows系统代理设置的软件，请在 Clash Verge 的“设置”中开启 Tun 模式 (Tun Mode)。 系统会自动安装虚拟网卡，接管电脑所有底层TCP/UDP流量。

四、Windows 常见疑难杂症

  • 关掉软件后电脑连不上网：这是由于退出软件时未正确关闭“系统代理”。打开 Windows 设置 -> 网络和Internet -> 代理，关闭“使用代理服务器”开关即可立即恢复；
  • UWP 应用（如微软商店）无法连接：在 Clash Verge 设置中点击“Windows UWP 回环代理免疫工具”，全选并保存即可解除微软对本地代理的沙盒限制。
