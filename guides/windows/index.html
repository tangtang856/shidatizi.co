Windows 10/11 电脑 Clash Verge Rev 配置与使用完整教程

详细图文指引Windows 10/11系统配置Clash Verge Rev客户端。涵盖订阅导入、系统代理、Tun虚拟网卡接管、游戏低延迟代理与常见报错解决。

在 Windows 10 与 Windows 11 环境下，Clash Verge Rev 是目前最受推崇的现代化代理图形客户端。 它基于 Tauri 框架打造，内存占用仅几十兆，深度集成了经过社区长期审计的 Mihomo (Clash.Meta) 内核，并原生支持 Tun 虚拟网卡模式。

💡 新手前置须知： 在配置客户端之前，请先准备好优质的机场节点订阅链接（如 微风网络 Breezenet 或 隐形人 等服务商后台获取的 Clash 格式链接）。

一、软件下载与安装

  1. 访问官方开源 Releases 页面下载安装包（认准 Clash.Verge_x64-setup.exe）；
  2. 建议右键选择“以管理员身份运行”以确保后续 Tun 网卡驱动能正常安装；
  3. 安装完成后启动软件，首次运行会自动在后台加载内核并释放默认配置。

二、导入机场订阅链接

  1. 点击左侧导航栏的 「订阅 (Profiles)」 选项；
  2. 在顶部输入框粘贴你的机场订阅 URL，并在名称处备注机场名称；
  3. 点击右侧 「保存 (Save)」，软件将自动发起 HTTP 请求下载最新节点列表；
  4. 右键点击已下载的配置卡片，选择“使用 (Select)”将其设为当前活动配置。

三、开启代理与分流模式选择

Clash Verge Rev 提供了三种核心运行模式：

  • 规则模式 (Rule - 推荐)：自动根据访问的域名分流，国内网站（百度、淘宝、微信）直连不消耗机场流量；国外网站（Google、YouTube、ChatGPT）自动走代理；
  • 全局模式 (Global)：电脑上所有流量全部强制走代理节点，可能导致国内 APP 定位异常或速度变慢；
  • 直连模式 (Direct)：不走任何代理，相当于直接连公网。

四、开启 Tun 虚拟网卡模式（解决游戏与终端不走代理）

常规系统代理只接管遵循系统 PAC 设置的浏览器等应用，而许多命令行工具（Git、PowerShell）或外服游戏客户端并不走系统代理。 在左侧点击 「设置 (Settings)」，找到 「Tun 模式 (Tun Mode)」 并点击安装服务核心，开启开关后，电脑所有网络流量将被虚拟网卡强制接管，实现类似全局 VPN 的极致体验。

五、常见报错与排查清单

  • 节点全部显示 Timeout 超时：首先校准电脑系统时间。若本地时间与网络时间误差超过30秒，TLS 握手将直接失败；
  • 开启代理后国内网站打不开：检查是否误开了“全局模式”，请切换回“规则模式”；
  • 启动报错 Service Install Failed：以管理员身份关闭杀毒软件或 Windows Defender 拦截后重新安装服务模式。
