什么是DNS污染与阻断？

📚 知识分类：网络代理基础架构 📅 核验更新：2026年3月 ✅ 校验：技术专家审校

DNS 污染 (DNS Cache Poisoning，又称 DNS 投毒) 是网络审查系统在公网国际关口局实施的主要技术手段之一。

一、工作原理

当用户的电脑向海外公共 DNS 服务器（如 8.8.8.8）发送未经加密的 UDP 53 端口查询请求时，防火墙的旁路监听设备会抢在真正的海外服务器之前，向用户伪造返回一个错误的虚假 IP 地址（通常指向不可达或空地址），导致用户浏览器无法建立正确连接。
